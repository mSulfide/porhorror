## 1. Общий сценарий пользования
Игрок заходит на сайт с игрой и попадает на экран входа. Где вводит свой ник и пароль если он зарегистрирован,
иначе переходит по кнопке "Зарегистрироваться" и регистрируется. После окна входа пользователь переходит на экран "Алтарь",
где расположен инвентарь и список комнат. С экрана алтаря пользователь переходит в комнату ожидания, где собираются игроки. После экрана комнаты игрок попадает на экран
с игрой, после на экран с итогом игры. С экрана итогов игрок возвращается в комнату. На каждом экране, кроме экранов со входом, игрой и итогами игры, есть возможность перехода на предыдущий экран (по кнопке "Выход").


## 2. Подробный сценарий пользования для каждого экрана
### 2.1 Экран входа
При заходе на сайт пользователь попадает первым делом на экран входа. На экране расположены: строка ввода ника, строка ввода пароля, кнопка регистрации и кнопка входа в игру. Если ник не найден в списке пользователей или пароль не совпадает с паролем из списка пользователей появляется надпись: "Неправильно введен ник или пароль".

После экрана входа пользователь может перейти на экран Алтарь (2.3), нажав на кнопку "Вход", или экран регистрации(2.2), нажав на кнопку "Регистрация".
### 2.2 Экран регистрации
При переходе по кнопке "Регистрация" пользователь попадает на экран регистрации. На экране расположены: строка ввода ника, строка ввода пароля, кнопка "Зарегистрироваться"

После экрана регистрации игрок переходит на экран входа(2.1).

### 2.3 Алтарь
При переходе по кнопке "Вход" пользователь переходит на экран "Алтарь". На экране расположены: Ячейки инвентаря, список комнат, рейтинг пользователей, ник пользователя с местом рейтинга, кнопка выхода, кнопка "Играть".

После экрана "Алтарь" пользователь может перейти на экран входа (2.1), нажав на кнопку "Выход", или в комнату (2.4), выбрав комнату и нажав кнопку "Играть".
### 2.4 Комната
При переходе по кнопке "Играть" пользователь попадает на экран комнаты. На экране расположены: количество игроков (по соотношению с макс количеством комнаты(3/4)), код комнаты, кнопка выхода из комнаты. После набора необходимого количества игроков раунд автоматически начинается и игроков перекидывает на экран игры.

После экрана комнаты игрок может перейти на экран "Алтарь"(2.3), нажав кнопку "Выход" или на экран игры, дождавшись полного набора игроков.
### 2.5 Игра
Когда игра начинается, игрок попадает на экран игры. На экране расположено: задачи которые должен выполнить игрок, шкала прогресса выполнения задач всех игроков, таймер, кнопки управления (если игрок использует телефон), карта.

После окончания игры пользователь автоматически переходит на экран "Завершение игры"(2.6).
### 2.6 Завершении игры
После завершения игры игрок попадает на экран завершения. На экране расположено: ник победителя игры или надпись "ничья", кнопка выхода.

После экрана завершения игрок может перейти в комнату (2.4), нажав на кнопку выхода.
