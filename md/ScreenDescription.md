## 1. Общий сценарий пользования
Игрок заходит в игру и попадает на экран регистрации. Где вводит свой ник и пароль если он зарегистрирован, иначе переходит на экран регистрации. После чего заходит на алтарь (инвентарь). На экране алтпрь есть несколько кнопок перехода: Играть; ( Магазин;(В разработке)) и несколько слотов в которые можно положить предметы для бафов. На экране алтаря должен быть список комнат. После выбора комнаты и нажатия на кнопку "Играть", игрок переходит в комнату, где ожидает полного набора играков. На экране видно количество (по соотношению с макс количеством комнаты(3/4)), код комнаты по которому можно зайти, кнопка выхода из комнаты(возвращает на список комнат).   После набора необходимого количества игроков начинается раунд. Игрок появляется в определенной точке на карте (как в амонгасе типо в столовой, только что-то другое), всем раздаются задачи и запускается таймер. Происходит некий геймплей. В конце игры выводиться экран в зависимости от победителя: "Ничья" - в случаи окончания таймера, *ник игрока* - в случае победы одного из игроков. Выход в лобби комнаты.
После нажатия кнопки Настройки выводиться экран с настройками игры такие как: Настройка звука.
Алтарь. Личный кабинет игрока с персонажем, скином на персонажа, ником игрока, бонусами для игрока и тд.
Магазин. Магазин со скинами и бонусы.

## 2. Подробный сценарий пользования для каждого экрана
### 2.1 Экран входа
При заходе на сайт пользователь видит попадает первым делом на экран входа. На экране расположены: строка ввода ника, строка ввода пароля, кнопка регестрации и кнопка входа в игру. Если ник не найден в списке пользователей или пароль не совпадает с паролем из списка пользователей появляеться надпись: "Неправельно введен ник или пароль". 

После экрана входа пользователь может перейти на экран Алтарь (2.3), нажав на кнопку "Вход", или экран регестрации(2.2), нажав на кнопку "Регестрация".
### 2.2 Экран регестрации
При переходе по кнопке "Регестрация" пользователь попадает на экран регистрации. На экране расположены: строка ввода ника, строка ввода пароля, кнопка "Зарегестрироваться"

После экрана регестрации игрок переходит на экран входа(2.1).

### 2.3 Алтарь
При переходе по кнопке "Вход" пользователь переходит на экран "Алтарь". На экране расположены: Ячейки инвентаря, список комнат, рейтинг пользователей, ник пользователя с местом рейтинга, кнопка выхода, кнопка "Играть".

После экрана "Алтарь" пользователь может перейти на экран входа (2.1), нажав на кнопку "Выход", или в комнату (2.4), выбрав комнату и нажав кнпку "Играть". 
### 2.4 Комната
При переходе по кнопке "Играть" пользователь попадает на экран комнаты. На экране расположены: количество игроков (по соотношению с макс количеством комнаты(3/4)), код комнаты, кнопка выхода из комнаты. После набора необходимого количества игроков раунд автомотически начинаеться и игроков перекидывает на экран игры.

После экрана комнаты игрок может перейти на экран "Алтарь"(2.3), нажав кнопку "Выход" или на экран игры, дождавшись полного набора игроков.
### 2.5 Игра 
Когда игра начинаеться игрок попадает на экран игры. На экране расположено: задачи которые должен выполнить игрок, шкала прогресса выполнения задачь всех игроков, таймер, кнопки управления (если игрок использует телефон), карта.

После окончания игры пользователь автомотически переходит на экран "Завершение игры"(2.6).
### 2.6 Завершении игры
После завершения игры игрок попадает на экран завершения. На экране расположено: ник победителя игры или надпись "ничья", кнопка выхода.

После экрана завершения игрок может перейти в комнату (2.4), нажав на кнопку выхода.
